# MG4
## Devlog
The float animation script works by first moving the fish food down and decreasing _timer which is declared in the Start() method as the same value as _switchSpeed and in the Update() method, once the switch speed timer hits 0, the boolean _up changes to the opposite value which makes the fish food start going in the opposite direction by increasing/decreasing the y value.
